# 外部 Claude 出力(コレクション画面実装案)の検証記録

受領日: 2026-07-06 / 出力元プロンプト: v2(実型定義なし)

## 結論

受領した実装コードは**そのままでは動かない**。原因はすべて「実データ構造をプロンプトに
含めていなかったこと」による想像上のAPI参照であり、premortem 指摘(実型を渡せば品質2〜3倍)の
実証となった。v3 プロンプトには実際の型定義・シグネチャ・デザイントークンを埋め込み済み。

## 外部出力から採用したアイデア(本リポジトリの実装に反映済み)

- **全体達成率の表示**: 全マップ合算の開放数/総数+進捗バーをモーダル上部に追加。
- **100%達成時の 🏆 表示**: 全国マップ・各マップの行に完全制覇バッジを追加。
- **一覧の肥大化対策**(潜在的欠陥1・2への対応): 未開放チップは12件まで表示し、
  残りは「+N」に畳む方式を採用。展開式アコーディオンは、日本以外のマップに
  コード→名称データが存在しないため、必要になった時点で導入する。

## 採用を見送った提案と理由

- **未開放地域の「???」表示(名前を隠す)**: 未開放の県名を見せることは「次にどこを
  狙うか」の行動喚起になり、実在の地名という本プロダクトの強みとも整合するため、
  実名表示を維持。ミステリー演出はアイコン/シルエット素材がある場合に再検討。
- **openedRegions(開放済み地域の全列挙)**: 市区町村モードでは数百件になり
  モーダルが破綻するため、開放数のみ表示。
- **地域名ローカライズ(潜在的欠陥3)**: 既存の `PREFECTURES.nameEn` と
  `getMapName(code, undefined, language)` で日英は解決済み。第三言語は現時点でスコープ外。
